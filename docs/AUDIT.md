# Yiasemi website: audit, defect report & release notes

## 1. Architecture (as found and as delivered)

| | Found | Delivered |
|---|---|---|
| Stack | Static HTML/CSS/JS generated by `build.py` (Python), no framework, no npm runtime deps | Same (kept deliberately: fastest, cheapest, least to break) |
| Content | Café facts and an **invented** menu hard-coded in `build.py` | Single source of truth: `content/site.json` and `content/menu.json` (validated at build) |
| Routes | `/`, `/menu`, `/photos`, `/visit`, `/credits` + `/el/...` | Same, plus `/privacy` and `/el/privacy`; branded 404 |
| JS | One file, progressive enhancement | Same; every page works with JS disabled (tested) |
| Hosting | Vercel project `yiasemi`, served through a jsDelivr proxy (Vercel GitHub app has no repo access) | Same proxy, now with full security headers (see §6) |
| Tests | None | Python unit tests (17), Playwright E2E (34 tests × 3 device profiles = 102), axe-core, Lighthouse |

## 3. Tests executed (latest run)

- `python3 -m unittest discover -s tests/unit`: **17 passed** (URL building, EUR formatting per language, menu validation, dietary-label sanity on real data, opening-hours rendering, map links).
- `npx playwright test`: **102 passed** (34 tests × desktop Chrome, Pixel 7, 390px touch): every route both languages (status, lang, single h1, title, description, canonical, hreflang, valid JSON-LD, zero console errors, **zero third-party requests**); 404; no placeholder prices or clock; 90 menu items with correctly formatted prices in EN (`€6.50`) and EL (`6,50 €`); search (incl. accent-insensitive Greek); empty state; dietary filters; category nav and scroll-spy; no-reload language switch with back/forward; all nav links; light default and theme persistence; mobile menu with Escape and focus return; gallery filters; lightbox open, keys, swipe, Escape, focus return; tel/Google/Apple directions links; map not loaded until clicked; axe WCAG 2.2 AA in light & dark (0 serious/critical); no horizontal overflow at 320/360/390/430/768/1024/1280/1920px; images load with alt and dimensions; content visible with JS disabled.
- **Production run** (`BASE_URL=https://yiasemi.vercel.app`, desktop + Pixel 7): 65/68 passed. The 404 test fails as expected (defect #6, the proxy shows jsDelivr's 404 text). One lightbox run failed once on slow image loading and did not reproduce in 41 reruns (36/36 stress run). That run also exposed a real swipe bug (viewer only swipeable on the image while loading), now fixed.
- **Not tested:** Safari, Firefox, real iOS and Android devices. Only Chromium is installed in this environment, and installing others is not permitted here.

## 4. Accessibility
WCAG 2.2 AA target. Automated axe: 0 serious/critical violations across all main pages in both themes. Manual: keyboard order, visible focus ring, skip link, focus moved to `<main>` on page swap, dialog focus trap and return, `aria-current` for page and category, `aria-pressed` on toggles, live-region result counts, reduced-motion respected, 44px+ touch targets. Screen-reader testing on real NVDA/VoiceOver was **not** performed.

## 6. Security
No secrets, keys or environment variables exist in the project. Headers: CSP `default-src 'self'` with a sha256-hashed inline theme script, `frame-src` limited to Google Maps, `object-src 'none'`, `frame-ancestors 'self'`; HSTS; `X-Content-Type-Options`; `Referrer-Policy`; `Permissions-Policy`. There are no forms, so there is no input handling, rate limiting or auth surface. `style-src 'unsafe-inline'` is required for inlined critical CSS.

## 7. Not built, and why
- **Menu admin / CMS**: no confirmed need, and a real one requires a database plus authentication, which needs client decisions and accounts. Recommended: once the Vercel GitHub app has access, add Decap CMS (GitHub login) editing `content/menu.json`. That gives real persistence, auth and validation, and the build fails on bad data.
- **Contact form / reservations / group enquiries**: no official email, booking process or approval. The phone is the only verified contact channel.
- **Cookie banner**: not required. The site sets no cookies and loads no third-party resources until the visitor asks for the map (disclosed in place). Add a consent system **before** any analytics (GA4 needs client approval).
- **GeoCoordinates / opening hours in schema**: not verified, so omitted. The fields exist and render automatically once filled.

## 8. Incident: "€ —", "Athens time –:–" and "indicative" reported on the live menu (re-investigated)
**Finding:** the current production deployment does **not** contain any of these (verified with curl and a fresh browser on production; see release check below). They exist only in the build from commit `cfe1b8e` and earlier.
**Root causes:**
1. Earlier deployments remain reachable at their own `yiasemi-<hash>-gm-designs.vercel.app` URLs (team-login protected), and they show old code.
2. During the proxy workaround, some page responses carried jsDelivr's `Cache-Control: max-age=604800`, so a browser could keep showing an old copy for up to 7 days.
3. Code defect: in-site navigation used `fetch()` with the default cache mode, which accepts a still-fresh cached copy. **Fixed:** `cache: "no-cache"` (forces revalidation; covered by an E2E test).

**Also changed:** removed the unverified "including VAT" claim; added the EU-14 allergen system (`sitegen/core.py`, `tools/allergens.py`, `docs/allergen-form.csv`) with tests; added a menu source line ("as published by Yiasemi on yiasemi.gr").
